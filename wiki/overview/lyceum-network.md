# The Lyceum network

This repo is the **source of truth** for a three-repo network:

| Repo | Role | Editable |
|---|---|---|
| `melchizedek/` | Private framework — YAMLs, libraries, schema, servers, this bundle | Yes; changes start here |
| `melchizedek-agents/` | Sanitized public mirror, generated by the [export pipeline](/operations/export-pipeline.md) | Never by hand |
| `lyceumagents/` | The teaching site (lyceumagents.com); lessons, dialogues, and downloads mirror this repo's YAMLs and memory pipeline | Yes, but only to match the source of truth |

## The doctrine

Facts deliberately live in several places — a prompt is taught in a lesson, downloadable as markdown, shipped in two repos. The covenant: **when a fact changes here, every mirror updates in the same pass.** The workspace `lyceum-sync` skill maps the known chains; the update order is fixed:

1. Edit the source of truth here (YAML / lib / db), typecheck.
2. Sync this repo's own docs (README/DOCUMENTATION SQL blocks and their overlay twins — the [schema](/memory/schema.md) is mirrored in four places by design).
3. Regenerate the public repo via the [export pipeline](/operations/export-pipeline.md) — it scans, tests, and commits, but never pushes.
4. Sync the teaching site under its own workflow, then grep each changed fact across all three repos.

## Where this bundle fits

The wiki is the network's queryable memory of itself. Public-safe knowledge lives in the open subtrees and exports with the tool layer; knowledge that must not leave this repo lives under `/private/` and is excluded structurally ([decision 0003](/decisions/0003-path-based-visibility.md)). The site's own `knowledge/` directory remains its own bundle-shaped corpus — the wiki tooling is bundle-root-agnostic (`WIKI_ROOT`) and can serve it unchanged.
